# Speak Or No Speak
I want to solve the following problem: When I want to talk to my computer by voice input then I usually have to start and stop the microphone / recording
I want to create some Javascript code that can determine reliably if a person is speaking or not so it then can make an action - for example: a chatbot is answering the question.
The app shall also recognize when the user is speaking (again) while an action is performed - let's say: a chat bot is answering - and interrupts it's action because the user is interrupting by speaking.

So, the usecase where I want to use this in the end is as some kind of code module for an AI application.
Let's say: I want to control a game avatar by voice command or something like this.

I want a light weight solution for this "speak-or-no-speak" problem. But it also shall be reliable. So I could also imagine a solution that is using a speech-to-text model for getting the speech content and a decision model to check if a sentence is done. Something like that.
